# Evidence Workbench (working name)

A workbench for clinicians that navigates, compares, audits and verifies clinical evidence: every claim
is tied to a code-verified verbatim quote, graded for certainty and strength, and shown as an algorithm,
evidence map, concordance matrix or pathophysiology diagram. It does not give patient instructions.

Built for the Meta Global AI Developer Hackathon (Indie track). Design planning (this `docs/` folder) was
written before the building period (Oct 27 – Nov 4, 2026); all application code is written during it.

Start with `CLAUDE.md`, then `docs/SPEC.md` and `docs/architecture/`.
