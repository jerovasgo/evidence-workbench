# Evidence Workbench (working name)

A workbench for researchers, engineers and students that navigates, compares, audits and verifies
scientific evidence — any field of science, explicitly excluding clinical medicine: every claim is
tied to a code-verified verbatim quote, graded for certainty, and shown as an algorithm, evidence
map, concordance matrix or mechanism diagram. It does not give instructions to act on a specific
real-world case.

Built for the Meta Global AI Developer Hackathon (Indie track). Design planning (this `docs/` folder) was
written before the building period (Oct 27 – Nov 4, 2026); all application code is written during it.

Start with `CLAUDE.md`, then `docs/SPEC.md` and `docs/architecture/`.
